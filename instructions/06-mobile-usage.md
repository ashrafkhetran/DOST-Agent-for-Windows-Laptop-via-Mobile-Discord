# 06 - Mobile usage
Open Discord on your phone, DM the bot (or use the private server channel). Try:
`hello`, `/shot`, `/status`, `/processes`, `/audit`, "show files in my Downloads", "open notepad", or send a voice note (English/Urdu).
Other commands: `/new`, `/stop`, `/voice on|off|auto`, `/panic`, `/help`. Risky actions show Approve/Deny buttons.
