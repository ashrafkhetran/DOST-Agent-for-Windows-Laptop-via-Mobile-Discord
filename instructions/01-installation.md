# 01 - Installation
Requires Windows 10/11 and Python 3.10+ (tested on 3.14).
1. Double-click `install.bat` (creates `.venv`, installs `requirements.txt`, creates `.env`).
2. Manual alternative: `python -m venv .venv` then `.venv\Scripts\python.exe -m pip install -r requirements.txt`.
3. For `BRAIN=subscription`, install Claude Code (`npm i -g @anthropic-ai/claude-code`) and log in once with `claude`.
