# 05 - Running
Double-click `START_DOST.bat` (or `run.bat` for an auto-restarting console). Direct: `.venv\Scripts\python.exe -m agent.main`.
Stop with `STOP_DOST.bat` or `/panic` from Discord. Optional login startup: `INSTALL_AUTOSTART.bat`.
Success looks like: no "Setup incomplete" message, and the bot shows Online in Discord.
